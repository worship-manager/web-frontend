Worship teams rarely live on one laptop. Someone prep’s the set mid-week; someone else runs the booth on Sunday. **Sync Songs** moves your lyric library between Worship Manager installs on the same network without USB sticks or retyping.

## When to use Sync Songs

- Copy the office library onto the sanctuary computer before service
- Share a new song the worship leader just added
- Keep a backup machine roughly in sync with the main booth PC

Sync is for **songs** (titles + lyric blocks). Media files are separate — import those on each machine (or from shared storage) as needed.

## Open Sync Songs

1. Go to the **Songs** tab (`Ctrl + S`).
2. Click **SYNC SONGS**.

You will see options to **start sharing** (this computer is the source) or paste a **share address** to receive from another computer.

## Share from the source computer

On the machine that already has the songs:

1. Click **start sharing**.
2. Worship Manager shows a **Sharing Address**.
3. Leave this dialog open while the other computer connects.
4. When you are done, click **stop sharing**.

Both computers need to reach each other on the local network (same Wi‑Fi/LAN, no guest isolation blocking device-to-device traffic).

## Receive on the other computer

On the machine that needs the songs:

1. Open **SYNC SONGS**.
2. Paste the sharing address into **Share Address**.
3. Connect / receive — you will get a list of song titles available from the source.
4. Filter the list if it is long.
5. Check the songs you want (or select all).
6. Finalize to save them into the local library.

You do not have to import everything. Pull only the set list if that is all you need for Sunday.

## A simple Sunday workflow

1. Mid-week: build or update songs on the prep laptop.
2. Before service: start sharing on the prep laptop (or the machine with the latest library).
3. On the booth PC: receive, select the songs for this week, finalize.
4. Stop sharing on the source.
5. Spot-check titles and a lyric block or two in Present.

## Tips and gotchas

- Prefer a wired network or solid Wi‑Fi — flaky guest networks are the usual failure point
- If the address does not connect, confirm both apps are open and that the firewall allows the connection
- After sync, edit conflicts are just “whichever copy you keep” — sync again if someone edited the same song on two machines
- Pin the service’s songs after import so they are one click away
