When the service is moving, the mouse is slow. Worship Manager’s shortcuts keep your hands on the keyboard for the actions you repeat every Sunday: switching tabs, clearing the screen, and toggling Present.

All of these use **Ctrl** plus a letter (defaults below). Hover a tab to see its current shortcut tip as well.

## Selector tab shortcuts

| Action | Default |
| --- | --- |
| Jump to Pinned | `Ctrl + P` |
| Jump to Songs | `Ctrl + S` |
| Jump to Bible | `Ctrl + B` |
| Jump to Media | `Ctrl + M` |
| Jump to History | `Ctrl + H` |

## Display action shortcuts

| Action | Default |
| --- | --- |
| Toggle Present | `Ctrl + T` |
| Clear Display | `Ctrl + D` |
| Clear Overlay Text | `Ctrl + X` |

**Clear Overlay** removes song/scripture text. **Clear Display** clears media and overlay together. **Toggle Present** opens or closes the display window — the same idea as the PRESENT / STOP button.

## A fast live pattern

1. `Ctrl + M` → put up the welcome slide
2. `Ctrl + S` → run the worship set lyric by lyric
3. `Ctrl + X` → clear lyrics between songs if the background should stay
4. `Ctrl + B` → scripture reading
5. `Ctrl + D` → full clear before the message media
6. `Ctrl + P` → jump to anything you pinned for curveballs

Practice that sequence once in rehearsal and it becomes muscle memory.

## Customize anything that fights your hands

Defaults are sensible, but laptops and OS shortcuts sometimes collide. You can change every listed action:

1. Open **Settings**.
2. Find **Customise Keybinds**.
3. Click the letter field for an action and type a new key.

Worship Manager saves the change immediately. It will reject a key that is already assigned to another action (`DUPLICATE_KEYBIND`), so each shortcut stays unique.

For a focused walkthrough with screenshots, see [Configuring Keybinds in Worship Manager](/blog/configuring-keybinds).

## Tips

- Prefer letters you can hit without looking (home-row adjacent helps)
- Keep Clear Display on something hard to fat-finger mid-song
- If you share a booth PC, print this cheat sheet until the team learns the defaults
- Tab shortcuts + Pinned covers 90% of mid-service navigation
